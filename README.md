# EcoSort AI — AI-Powered Waste Management Platform

**SDG 12: Responsible Consumption and Production**

Upload a picture of any waste item — EcoSort AI instantly identifies whether it belongs in **recycling**, **compost**, **landfill**, **e-waste**, or **hazardous waste**, with disposal guidance and sustainability tips. Built with FastAPI, HuggingFace, and OpenAI/Gemini vision models.

---

## Features

### Core: EcoSort AI Waste Classifier
- Upload a photo of waste → AI classifies into 5 disposal categories
- Per-item disposal guidance and sustainability tips
- Confidence scoring for each classification
- Professional SVG icon system for waste categories

### Full Platform
- **Digital Fridge** — Track ingredients with expiry alerts
- **Recipe Matcher** — AI generates recipes from leftover ingredients (HuggingFace T5 model; falls back to catalog/web search)
- **Meal Planner** — 3–7 day plans with auto grocery lists
- **Surplus Sharing** — Local food sharing network
- **Social Features** — Food posts, follows, messaging, notifications
- **Restaurant Discovery** — Map-based search with filters

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python, FastAPI, Uvicorn |
| AI/Vision | OpenAI GPT-4o, Google Gemini, HuggingFace |
| Recipe Model | `flax-community/t5-recipe-generation` |
| Embeddings | `sentence-transformers/all-MiniLM-L6-v2` |

## Setup

```bash
git clone https://github.com/hirahmad1/ecosort-ai.git
cd ecosort-ai
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
```

### Environment Variables

Create a `.env` file in the project root:

```env
# Required — AI Vision (at least one)
OPENAI_API_KEY=sk-...
GOOGLE_API_KEY=...

# HuggingFace
HF_TOKEN=hf_...
HF_RECIPE_MODEL=flax-community/t5-recipe-generation
HF_MODEL=sentence-transformers/all-MiniLM-L6-v2

# Database (optional — uses SQLite if not set)
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB=ecosort_ai
```

## Run

```bash
.venv\Scripts\activate
uvicorn backend.main:app --reload --host 127.0.0.1 --port 8001
```

Or double-click `start-server.bat` on Windows.

Open **http://127.0.0.1:8001**

## API Endpoints

### Waste Classification
```
POST /api/ecosort/classify
Content-Type: multipart/form-data

file: <image>
```
Returns classified waste items with category, confidence, disposal guidance, and sustainability tips.

### Recipe Matching
```
POST /api/match
Content-Type: application/json

{ "ingredients": ["tomato", "egg", "onion"], "top_k": 5 }
```
Recipes are generated by `flax-community/t5-recipe-generation` with catalog/web search fallback.

### Fridge Scan
```
POST /api/pantry/scan
Content-Type: multipart/form-data

file: <image>
```
AI-powered food item detection for the digital fridge.
